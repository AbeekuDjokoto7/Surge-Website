# Surge → React conversion spec

Copy this file into a new repository and follow it to rebuild Surge as a React app that looks and behaves like the current Rails site.

Do **not** redesign. Port markup, Tailwind classes, tokens, assets, routes, and copy.

---

## 0. What this app is today

Source stack:

- **Ruby on Rails 8.1** + **Ruby 4.x**
- **Hotwire** (Turbo + Stimulus)
- **Tailwind CSS v4** + custom brand tokens
- **Plutonium** admin (posts, categories, users)
- **Rodauth** staff auth at `/users`
- **SQLite** + Solid Queue / Cache / Cable
- **Postmark** for email

The public site is mostly server-rendered ERB. The dashboard UI is generated by Plutonium. Auth is Rodauth (not Devise).

---

## 1. Goal

A React app that matches the current site:

1. Same public URLs
2. Same layout, typography, colors, spacing, images
3. Same nav, footer, dropdowns, carousels, accordions, modals
4. Same contact + apply forms (email, not DB)
5. Same public blog (published posts only)
6. Optional later: staff dashboard + auth

### Non-goals unless explicitly required

- Pixel-cloning Plutonium admin chrome
- Recreating every Rodauth feature (lockout tables, audit logs, active sessions)
- Public self-serve signup (already blocked in Rails)

### Backend options

| Option | When to use |
|---|---|
| **A. Next.js UI + keep Rails as API** | Fastest way to keep blog/email/auth identical |
| **B. Next.js full-stack (Prisma + Postgres)** | Cleaner long-term, more work |

**Recommended v1:** Option A for data, or static + email APIs only if the blog can wait. Leave `/dashboard` and `/users` on Rails until the public site matches.

## 2. Create the new repo

```bash
npx create-next-app@latest surge-web --typescript --tailwind --app --src-dir --eslint
cd surge-web
npm install @heroicons/react @tabler/icons-react react-markdown
```

Use:

- **Next.js App Router** (SSR/SEO — this site has OG, JSON-LD, canonicals)
- **React + TypeScript**
- **Tailwind CSS v4**
- **@heroicons/react** for `heroicon` replacements
- **@tabler/icons-react** for Facebook / LinkedIn / Instagram
- **next/image** for photos; inline SVGs as React components
- **react-markdown** for post bodies
- **Postmark or Resend** for contact/apply emails

Do **not** use a Vite SPA if you want the same SEO.

Place this markdown file at the new repo root.

A ready-to-copy pack lives in **`react-conversion-kit/`** in the Rails repo:

- this spec
- all public images (same paths as Rails `image_tag`)
- Tailwind config + CSS

See `react-conversion-kit/README.md` for copy commands.

## 9. Stimulus → React

Do not keep Stimulus. Recreate each controller as a hook/component.

### `mobile-menu`

- Targets: button, menu, openIcon, closeIcon
- Toggle `hidden` on menu
- Swap hamburger / close icons
- Set `aria-expanded`
- While open, add `overflow-hidden` to `html` and `body`

### `dropdown-nav`

- Click trigger toggles that dropdown
- Opening one closes the others
- Click outside (`[data-dropdown-content]` / `[data-dropdown]`) closes all
- `aria-expanded` on triggers

### `slideshow`

- Gap = **24px**
- `next`: `scrollBy({ left: slideWidth + 24, behavior: "smooth" })`
- `previous`: same, negative
- Disable conceptually when at start/end (`scrollLeft`, `scrollWidth - clientWidth`)
- Home cards: `min-w-[311px] md:min-w-[370px]`, `snap-x snap-mandatory`, mobile overflow scroll, desktop overflow hidden

### `accordion`

- Only one section open at a time
- Toggle collapses if already open
- Optional `autoExpandFirst`
- Content uses `hidden`; icon rotates `180deg` when open

### `faq` (FAQ index filters)

- Filters: `all | loans | deposits | general`
- Active chip: `bg-[#FFF3E5] text-[#E85C0D] cursor-default`
- Inactive: `bg-[#F4F4F6] text-[#5A5B5D]`

### `collapsible`

- Independent expand/collapse
- Toggle `hidden` + rotate icon 180°

### `share`

- Values: title, text, url (default `location.href` / `document.title`)
- Facebook: `https://www.facebook.com/sharer/sharer.php?u=`
- X: `https://twitter.com/intent/tweet?url=&text=`
- Popup `600×540`, centered
- If no network and `navigator.share` exists, use Web Share API

### `modal` (board bios)

- Open with name, title, image, full bio
- Layout: image `md:w-1/3` aspect 3/4 rounded-xl; text `md:w-2/3`
- Bio: split `\n\n` into paragraphs
- Overlay fade; panel `opacity` + `translate-y-4` / `sm:scale-95` for 300ms
- Escape closes; lock body scroll while open

### `dashboard` (admin only)

- Count-up stats (~20 steps)
- Filter recent posts by status
- Animate chart bars `scaleX` from 0
- Refresh interval default 3600s; manual refresh updates “Last updated: h:mm AM/PM”

## 11. Data models (if you rebuild the API)

```ts
type PostStatus = "published" | "draft" | "archived" // 1, 2, 3

type Post = {
  id: number
  title: string
  body: string          // markdown / HTML from Action Text
  body_text: string     // plain text, markdown stripped
  status: PostStatus
  published_at: string | null  // set when published, else null
  category_id: number
  user_id: number
  cover_image_url: string | null
  created_at: string
  updated_at: string
}

type Category = { id: number; name: string } // unique name

type User = {
  id: number
  email: string
  status: "unverified" | "verified" | "closed"
}
```

Public API returns only `status === "published"`.

On save (admin): if body changed, strip markdown into `body_text`. If published, set `published_at = now`, else null.

## 14. ERB → JSX rules

1. `class=` → `className=`
2. `<%= value %>` → `{value}`
3. `<%= link_to x, path %>` → `<Link href={path}>`
4. `<%= image_tag "foo.jpg" %>` → `<Image src="/foo.jpg" />` (match public path)
5. `<%= inline_svg "bar.svg" %>` → React SVG component
6. `<%= heroicon "arrow-left", variant: :solid %>` → `@heroicons/react/24/solid`
7. Tabler icons → `@tabler/icons-react`
8. `<%= form_with %>` → `<form onSubmit>` calling the API
9. `content_for :title` / meta → `generateMetadata()`
10. Do **not** rename Tailwind classes
11. Screenshot at **375px** and **1440px** after each page
